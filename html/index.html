🩷 Tutorial Básico de Git 🩷

¿Qué es Git?

Git es un sistema de control de versiones distribuido que permite registrar los cambios en el código fuente a lo largo del tiempo. Es útil para colaborar, revertir errores y llevar un historial completo del proyecto.

¿Qué es GitHub?

GitHub es una plataforma web que permite alojar repositorios Git. Funciona como una red social para desarrolladores y facilita el trabajo colaborativo.

Configuración inicial

git config --global user.name "Tu Nombre"
git config --global user.email tucorreo@example.com

Comandos básicos

  • Inicializar repositorio:
    • git init
  • Cambiar rama principal a main:
    • git branch -m main
  • Ver estado:
    • git status
  • Agregar archivos:
    • git add .
  • Hacer commit:
    • git commit -m "Mensaje"
  • Ver historial:
    • git log --oneline

Ramas (Branch)

Una rama es una versión independiente del proyecto donde puedes trabajar sin afectar la principal. 

git branch nombre_rama
git switch nombre_rama

Deshacer cambios

  • Restaurar archivo:
    • git restore archivo.txt
  • Reset suave:
    • git reset --soft HEAD~1
  • Reset duro (peligroso):
    • git reset --hard HEAD~1

.gitignore

Es un archivo que indica a Git qué archivos ignorar para evitar subir archivos innecesarios. 

*.log
.env
/build/
.vscode/

Comparar cambios

git diff
git diff --staged
git diff rama1 rama2

Subir a GitHub

git remote add origin URL
git push -u origin main

Otros comandos útiles

  • Guardar cambios temporales: git stash
  • Ver historial de acciones: git reflog
  • Etiquetas: git tag -a v1.0 -m "Versión 1.0"
